# 实施计划：通用语义 Sheet 归并

## 范围

在现有统一整合引擎上增加工作簿级通用的 Sheet 语义归并能力：总表和更新文件的全部 Sheet 都按内容而非 Sheet 名识别主题；命中已有总表主题后自动映射和覆盖，只有不唯一或互相矛盾的情况进入独立人工处理队列。该层不依赖现有五个薪资实体，因此适用于其他公司、其他总表和未知业务主题。本期不改变数据库结构，不实现跨月份的公司记忆库。

## 架构决策

- 新增独立于薪资实体的工作簿语义层，以可解释的确定性评分（表头语义、字段类型、候选业务主键、数据区块）处理所有 Sheet，不以大模型作账务判断。
- 自动条件必须同时满足主题、业务主键、字段和来源优先级均唯一；除此以外默认自动更新，包括部门和岗位。业务主键可为人员、单据、项目或唯一行指纹，而非限定为工号。
- 继续复用 `core/unified_integration.py` 的来源追溯、人工问题导出及公式完整性校验；薪资实体解析只作为现有工资计算路径，不限制通用 Sheet 层；不改 `schema_config.py` 的实体定义或 `EXPORT_MAPPING`。
- “公司记忆”留为后续独立任务，届时以租户隔离的可审计映射规则表实现，不能用进程内 memory 代替。

## 依赖图

```
所有 Sheet 的画像与主题评分
        ↓
唯一主题/字段/人员解析 ──→ 异常事项生成
        ↓                         ↓
总表目标 Sheet 更新 ───────→ 独立人工处理工作簿
        ↓
现有公式完整性与端到端导出验证
```

## 任务

### T1：工作簿级主题画像与唯一匹配判定（核心，M）— 已完成

**描述：** 为总表和来源工作簿的所有 Sheet 生成结构化画像，推断表头、数据区块和候选业务主键；依据字段覆盖、数据类型和数据形态计算候选主题，只输出唯一高置信度结果。

**验收：**

- [ ] “人员异动”与“人员变更”在表头/内容相同或高度相似时命中同一主题。
- [ ] 不含人员字段的未知业务 Sheet 也能通过其自身业务主键匹配到同主题总表 Sheet。
- [ ] 名称相似但字段结构不同的 Sheet 不自动归并。
- [ ] 候选并列或低置信度时返回可追溯人工事项。

**验证：** `python -m pytest -q tests/test_unified_integration.py`

**依赖：** 无

**预计文件：** `core/unified_integration.py`、`tests/test_unified_integration.py`

### T2：同主题自动映射与覆盖（核心，M）— 已完成

**描述：** 将唯一匹配的来源数据写入既有总表 Sheet；按推断出的稳定业务主键定位行和字段，唯一确定时用来源值覆盖旧值，并保留来源审计信息。

**验收：**

- [ ] 不同名称的同主题来源 Sheet 不新增目标 Sheet。
- [ ] 同一人员、同一字段在身份与映射唯一时直接覆盖，含部门和岗位。
- [ ] 原总表公式、样式及非目标 Sheet 不被破坏。

**验证：** 聚焦 pytest 用例及公式签名校验。

**依赖：** T1

**预计文件：** `core/unified_integration.py`、`tests/test_unified_integration.py`

### T3：最小人工兜底与交付衔接（M）— 已完成

**描述：** 仅为无法唯一判定的情形生成独立人工事项，明确问题、候选目标和来源；复用既有独立人工处理工作簿，不把其加入总表。

**验收：**

- [ ] 身份冲突、多目标候选、同优先级冲突三类情形产生人工事项。
- [ ] 其他高置信度变更不产生人工事项。
- [ ] 人工处理工作簿可追溯到文件、Sheet、行号和候选值。

**验证：** `python -m pytest -q tests/test_unified_integration.py` 与导出测试。

**依赖：** T2

**预计文件：** `core/unified_integration.py`、`tests/test_unified_integration.py`、必要时 `backend/routers/pipeline.py`

### 检查点：核心归并完成

- [x] 聚焦测试与完整 `python -m pytest -q` 通过。
- [x] 样本工作簿验证：主题归并、直接覆盖、异常人工和公式完整性均符合规格。
- [ ] 人工复核实现与规格一致后，才开始公司级记忆库的独立设计。

## 风险与控制

| 风险 | 控制措施 |
|---|---|
| 误把不同主题合并 | 仅唯一高置信度自动执行，其余进入人工 |
| 覆盖公式或样式 | 只更新数据单元格，复用现有公式签名校验 |
| 重复来源值彼此矛盾 | 明确来源优先级；并列时人工 |
| 规则随公司污染 | 本期不保存跨项目记忆；后续记忆强制租户隔离 |

## 非本期范围

- 公司级映射记忆库、长期规则管理界面和跨月自动学习；
- 数据库迁移、前端重写及 `schema_config.py` 公共实体定义变更。
