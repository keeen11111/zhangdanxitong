# 实施计划：安全财务账单批次（第一阶段）

依据 [安全财务账单批次规格](../docs/safe-financial-batch-spec.md)，先交付单人明确发布的安全闭环。

## 依赖

```text
安全 Sheet 映射
  → 草稿状态与控制校验
  → 发布端点与正式下载保护
  → 通用财务页面的草稿 / 发布状态
```

## 任务

### B1：草稿控制校验

- [x] 为空/无法画像的来源 Sheet 生成事项，不能默默忽略。
- [x] 根据映射和事项生成 `review_required`、`ready_for_release` 或 `blocked`。
- [x] 返回控制校验摘要与自动更新审计。

### B2：人工发布与下载保护

- [x] 发布端点只接受 `ready_for_release` 草稿。
- [x] 正式下载只接受 `published` 结果；草稿下载单独提供。
- [x] 发布状态和时间保存于当前批次元数据。

### B3：页面状态

- [x] 显示草稿、待处理、可发布或已发布。
- [x] 区分“下载草稿”和“发布后下载正式账单”。
- [x] 发布被阻止时显示原因。

### B4：正式版本留档

- [x] 发布前复制 Excel 至独立归档，并记录版本 ID、发布人、发布时间与控制校验。
- [x] 已发布版本使用归档文件下载，不受后续上传或重新整合影响。
- [x] 归档文件记录并校验 SHA-256；校验不一致时拒绝下载。
- [x] 页面展示正式版本历史，并支持按版本下载。

## 验证

- 全量后端测试。
- 前端 lint 与生产构建。
