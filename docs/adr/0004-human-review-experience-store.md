# ADR-0004: 本地、租户隔离的人工审核经验库

- 状态: Accepted
- 日期: 2026-08-24
- 决策者: 项目团队

## 背景

薪资处理中的差异审核需要不断积累人工判断，但当前需求明确不接入大模型或外部 API。经验必须可审计、可控，并且绝不能因为历史案例而自动修改薪资数据。

## 决策

新增本地 JSON 经验库：每条规则包含非个人标识的匹配条件、人工决定和处理说明。文件按租户标识的哈希分别保存；读取、保存和建议接口均先验证项目属于当前登录用户的租户。

经验匹配采用精确字段匹配，只返回建议。保存经验时会同步确认或忽略当次差异，但未来命中规则不自动改变差异状态。

## 替代方案

### 接入大模型

可处理模糊语义，但不符合当前“不接模型”的约束，且会增加外发数据、成本与不可预测性。

### 在现有数据库中新增经验表

更适合高并发和统一审计，但需要数据库 schema 变更与迁移。当前先以本地、可迁移的 JSON 格式交付最小闭环。

### 在浏览器中保存规则

实现简单，但不能在不同设备或服务进程间复用，也缺少租户边界控制。

## 后果

**好处**：不增加依赖、不调用外部服务；人始终掌握最终决定；规则可复查并按租户隔离。

**代价**：当前只支持精确匹配，本地 JSON 不适合多进程并发写入。系统迁移至 PostgreSQL 后，应将经验规则迁移为具备审计字段的租户表。
